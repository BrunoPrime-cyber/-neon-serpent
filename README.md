# Neon Serpent - Cyberpunk Arcade Game (Godot 4.7)

A sleek, futuristic cyberpunk Snake game built with **Godot Engine 4.7 (GDScript)**.

![Neon Serpent Screenshot](assets/icons/menu_backdrop.png)

## Features
- **Cyberpunk Aesthetic:** Holographic arena, pulsing grid, glowing neon snake with animated eyes and ghost trails.
- **Dynamic Power-Ups:**
  - ⚡ **EMP Overclock Slow:** Slows game speed by 40% for 6.0s.
  - 👻 **Ghost Phase Shift:** Slither through your own tail segments without dying.
  - ★ **2X Data Stream:** Double score multiplier on all energy cores.
  - 🔥 **Tail Purge:** Incinerates 3 tail segments to escape tight corners.
- **Combo Multiplier:** Fast consecutive pickups ramp combo multipliers up to 4X with dynamic pitch-shifted chimes.
- **Procedural 16-bit Audio:** Synthesized sound effects (crystals, fans, glitch explosions) and a 120 BPM synthwave background track.
- **Cross-Platform Controls:** WASD / Arrow Keys on PC + Touch & Swipe gesture navigation on Android.
- **Interactive Start Menu & Briefing:** Start screen with tactical data overlays, how-to-play briefing, and pause menus.

## Controls
| Action | Key / Gesture |
|---|---|
| **Move** | `W, A, S, D` or `Arrow Keys` / Touch Swipe |
| **Start Game** | `Enter` or click `INITIALIZE LINK` |
| **Pause / Resume** | `P` or `Space` |
| **Restart** | `R` or click `REINITIALIZE LINK` |
| **Fullscreen** | `F11` or `Alt + Enter` |
